# Architecture Decision Records

Use an Architecture Decision Record (ADR) when a design choice changes the topology, segmentation, addressing, routing, service placement, security policy, or validation scope.

- Copy [ADR Template](adr-template.md) for each decision.
- Save records in this directory using the pattern `NNNN-short-title.md`.
- Link the decision from the relevant stage and update the [project roadmap](../../README.md) when project status changes.
- Record superseding decisions as new ADRs and link both records.
