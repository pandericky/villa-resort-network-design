# Villa Resort Network Infrastructure Design

This portfolio project documents the design and simulation of a small villa resort network in Cisco Packet Tracer. The planned scope covers back-of-house (BOH) connectivity, guest Wi-Fi separation, and reachability to a simulated upstream network.

**Project status** · Planned  
**Assessment scope** · Cisco Packet Tracer simulation. Production readiness requires separate validation outside this project.
